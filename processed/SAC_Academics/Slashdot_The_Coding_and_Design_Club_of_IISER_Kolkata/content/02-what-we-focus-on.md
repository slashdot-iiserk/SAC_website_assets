# What We Focus On

Slashdot's activities are organised around four broad themes:

- Web Development
- Data Science and AI/ML
- Simulations and Scientific Visualization
- Random Fun/Cool Stuff

## Tools & Technologies We Use

| Tool | Used For |
|---|---|
| Python Programming | General-purpose coding, scripting and simulations |
| Blender | 3D graphics, modelling and simulations |
| Manim | Mathematical and scientific animation |
| Illustrator | Vector graphic design |
| Canva | Quick, accessible graphic design |
